PRIVACY, IN PLAIN LANGUAGE

Your day is yours.
Here’s what the code shows.

This overview is based on the FlowWell extension manifest and implementation reviewed on October 22, 2026. Items marked “Needs confirmation” require the publisher’s input before this is a complete policy.

IN SHORT

FlowWell saves planner records in browser storage and uses Chrome alarms and notifications for reminders. The code reviewed does not show app-initiated requests to an external service.

01

Information FlowWell stores

FlowWell stores preferences in Chrome local storage under flowwell.preferences. Planner data—including routine details, scheduled and completed occurrences, and focus sessions—is stored in a browser IndexedDB database named flowwell.

Routine records may include a title, category, optional notes, selected days and time, time zone, duration for movement or meditation, and completion state. Focus records include the task name, session times, and duration. These are fields used by the extension code; they are not sent to an account service in the code reviewed.

02

Where the data goes

We found no app-initiated fetch, XMLHttpRequest, WebSocket, or beacon calls in the extension source reviewed. The storage and reminder implementation uses Chrome local storage, IndexedDB, Chrome alarms, and Chrome notifications.

The website may load fonts from Google Fonts. That applies to this marketing website, not the extension’s planner records. Confirm whether you want externally hosted fonts on the published website.

03

Permissions

  • storage: saves FlowWell preferences in Chrome local storage.
  • alarms: schedules routine reminders and focus-session timing.
  • notifications: displays reminder and focus completion notifications.
  • activeTab (optional): declared as an optional permission in the manifest; we did not find use of it in the implementation reviewed.

The content script is configured for HTTP and HTTPS pages. It can display the floating notch on those pages, read FlowWell state through the extension messaging layer, and is suppressed for domains the user has hidden. The code excludes Chrome extension pages.

04

Your controls

FlowWell settings let you hide the notch, choose its position, and list domains where it should not appear. The implementation also includes a delete-all-data action that clears routine, occurrence, and focus records and scheduled alarms and notifications.
